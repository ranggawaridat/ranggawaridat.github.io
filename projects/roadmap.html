🎯 Cara menggunakan roadmap

  • Centang materi setelah kamu bisa menjelaskan, mengimplementasikan, dan men-debug konsepnya.
  • Jangan hanya menonton atau membaca. Buat eksperimen kecil dan catat hasilnya.
  • Target belajar: sekitar 10–15 jam per minggu. Fase dapat tumpang tindih.
  • Checklist disimpan menggunakan penyimpanan lokal browser. Data tidak otomatis tersinkron ke perangkat lain.

Standar mastery: Explain → Implement → Debug. Bisa menjelaskan konsep tanpa catatan, membuat implementasi sendiri, dan menemukan akar masalah saat terjadi kegagalan.

01 · Go & Backend Fundamentals

Bangun kemampuan membuat API yang rapi, aman, teruji, dan mudah dipelihara.

Bulan 1–3

Go

Backend & API

Proyek fase 1: Production-style REST API dengan Go dan PostgreSQL: register/login, role-based access, validasi, migrations, logging, testing, dan Docker.

02 · Networking & Linux

Pahami perjalanan request dari client menuju aplikasi dan bagaimana OS mengelola koneksi.

Bulan 3–5

Networking

Linux & OS

Proyek fase 2: Telusuri satu request dengan curl, tcpdump/Wireshark, dan log aplikasi. Dokumentasikan DNS → TCP → TLS → HTTP → handler.

03 · Database Engineering

Berpindah dari sekadar menulis SQL menjadi memahami bagaimana database mengeksekusi dan menjaga konsistensi data.

Bulan 5–8

PostgreSQL & SQL

Proyek fase 3: Sistem inventory dan transaksi yang menangani pembelian bersamaan, stok terbatas, locking, rollback, dan idempotency.

04 · Go Concurrency & Performance

Pahami bagaimana program Go bekerja ketika banyak pekerjaan berlangsung bersamaan.

Bulan 8–11

Concurrency

Runtime & Performance

Proyek fase 4: Concurrent job processing system dengan worker pool, retry terbatas, cancellation, graceful shutdown, metrics, dan benchmark.

05 · Distributed Systems

Belajar merancang sistem yang tetap masuk akal ketika service, jaringan, atau dependency mengalami kegagalan.

Bulan 11–15

Building blocks

Proyek fase 5: Distributed order system dengan service terpisah, queue, retry, idempotency, cache, tracing, dan simulasi kegagalan dependency.

06 · Production, DevOps & Security

Siapkan aplikasi agar dapat dirilis, dipantau, dipulihkan, dan diuji keamanannya.

Bulan 15–18

Production engineering

Backend & API Security

Proyek fase 6: Deploy API Go ke server dengan CI/CD, observability, backup, secrets management, threat model, dan security assessment.

07 · Advanced Specialization

Pilih satu arah utama setelah fondasi systems engineering cukup kuat.

Bulan 18–24+

Jalur A — API Security Research

Jalur B — Distributed Systems Engineering

Jalur C — Low-level Systems

Portofolio akhir: Publikasikan minimal 3–5 artefak berkualitas: proyek Go, technical writeup, benchmark, security assessment lab, atau kontribusi open-source. Sertakan README, arsitektur, hasil pengujian, dan trade-off yang kamu ambil.

📚 Referensi belajar

  • Go: Go Tour, Go documentation, Let's Go — Alex Edwards.
  • Networking: Computer Networking: A Top-Down Approach.
  • Operating Systems: Operating Systems: Three Easy Pieces (OSTEP).
  • Database & systems: PostgreSQL documentation, Designing Data-Intensive Applications.
  • Security: OWASP API Security Top 10, OWASP Web Security Testing Guide, PortSwigger Web Security Academy.

Gunakan lab lokal, aplikasi yang kamu miliki, atau program yang memberikan izin pengujian secara eksplisit. Jangan menguji sistem pihak lain tanpa izin.
